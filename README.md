# Быырпах (Byyrpakh)

Якутский кисломолочный напиток для Minecraft Java 26.1.2

## Особенности
- Три стадии крепости (свежий → стоявший → крепкий)
- Ферментация 20 минут игрового времени
- Эффект "Весёлость" с 5 уровнями
- Цепочка крафта: закваска → молочная закваска → быырпах
- Бутылки можно ставить на блоки, до трёх на одно место (Shift+ПКМ)
- Напиток настаивается везде: в инвентаре, в сундуках, на земле и на блоке
- Бутылки встречаются в сундуках деревень, морских руин, затонувших кораблей и структур Нижнего мира

Список изменений по версиям — в [CHANGELOG.md](CHANGELOG.md).

## Установка
1. Установите NeoForge 26.1.2.114
2. Скачайте [последний релиз](https://github.com/Sokoris1/byyrpakh/releases)
3. Положите jar в папку mods/
